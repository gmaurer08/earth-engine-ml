# Machine Learning in Google Earth Engine

This repository contains my submission to the project on machine learning applications in Google Earth Engine for the Geomatics and Geoinformation course at Sapienza, A.Y. 2025/2026. The code is based on scripts shared by the instructors, Mattia Crespi and Alireza Hamoudzadeh, and adapted to the assignment. 

### Structure

The project is composed of three parts:
1. **K-means** land-cover clustering over the Mount Fuji area, with k=3,5,7, using data from *"USGS Landsat 7 Level 2, Collection 2, Tier 1"*
2. **SVM** binary classification between water and land pixels over Lake Victoria, with images from *"Landsat 8 Collection 2 Level-2, Tier 1 Surface Reflectance (SR)*".
3. **Random forest** land-cover classification over Camargue, with data from *"Sentinel-2 Surface Reflectance (SR)"*.

The description of all the data processing steps is available here: (project_report.pdf)[project_report.pdf]
